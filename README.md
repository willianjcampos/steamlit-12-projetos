Este repositório está relacionado a execução do curso "Streamlit: Crie 12 Aplicações Web de Inteligência Artificial", oferecido pelo professor Fernando Amaral, disponibilizado na Udemy. Aqui, estarão reunidos todos os projetos desenvolvidos ao longo do curso. Abaixo, encontram-se a lista dos projetos:

1. **Previsão de Custo para Abrir uma Franquia - Regressão Linear**: Aprenda a modelar e prever os custos iniciais para estabelecer uma franquia, usando técnicas de regressão linear.
2. **Previsão da Qualidade de Veículos - Classificação**: Desenvolva um sistema para avaliar e prever a qualidade dos veículos baseando-se em características históricas, utilizando algoritmos de classificação.
3. **Estimativa da Produção de Leite - Séries Temporais**: Utilize modelos de séries temporais para prever a produção de leite, analisando padrões temporais e sazonalidade.
4. **Avaliação da Probabilidade de Falha de Equipamentos - Distribuição de Poisson**: Implemente modelos estatísticos para prever a falha de equipamentos, aplicando a teoria da distribuição de Poisson.
5. **Análise da Normalidade dos Dados - Distribuição Normal**: Explore técnicas estatísticas para verificar a normalidade dos conjuntos de dados, essencial em muitas análises e inferências estatísticas.
6. **Sistema de Recomendação para Varejo - Regras de Associação**: Crie sistemas de recomendação usando algoritmos de regras de associação para sugerir produtos aos clientes no varejo.
7. **Benchmarking de Séries Temporais - Análise de Séries Temporais**: Compare séries temporais para benchmarking, utilizando métodos analíticos para avaliar e melhorar as previsões.
8. **Análise de Dados Públicos de Prestação de Contas - Análise Exploratória**: Investigue conjuntos de dados públicos relacionados à prestação de contas, empregando técnicas de análise exploratória de dados.
9. **Otimização do Lucro no Transporte de Carga - Algoritmos Genéticos**: Otimize as operações e maximize os lucros no transporte de carga, aplicando algoritmos genéticos para encontrar soluções ótimas.
10. **Produção de Imagens para Marketing - IA Generativa**: Explore a inteligência artificial generativa para criar imagens impactantes e inovadoras para campanhas de marketing.
11. **Análise de Dados da Bolsa de Valores - Análise Técnica**: Mergulhe nos mercados financeiros, utilizando análise técnica e exploratória para extrair insights de dados históricos da bolsa.
12. **Publicação de Dashboard de Dados na Web - Visualização de Dados**: Aprenda a construir e publicar dashboards interativos na web, facilitando a visualização e interpretação de dados complexos em tempo real.
